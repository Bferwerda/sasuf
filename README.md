# SASUF GenAI Student Survey — v17

Lean comparative survey for Sweden and South Africa.

## v17 design
- Each participant receives 5 randomly selected scenarios from a pool of 10.
- Each scenario has 7 responses: assistance choice, difficulty, stakes, meaningful added value, simpler-alternative adequacy, learning support vs. replacement, and resource–capability trade-off.
- Background/context sections retain the core variables needed for access, inclusion, AI literacy, sustainability, privacy awareness, skills/employability, and comparative interpretation.
- Final reflection contains decision-factor selection, one required synthesis question, and one optional university-support question.
- Study version: `2026-09-v17`.
- Participant-facing completion estimate remains approximately 10–15 minutes.

Deploy the contents of this folder to the existing GitHub Pages repository. The API endpoint remains configured in `SE/config.js` and `SA/config.js`.
