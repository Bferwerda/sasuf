# SASUF GenAI Student Survey — v18

Lean comparative survey for Sweden and South Africa.

## v18 design
- Each participant receives 5 scenarios from a pool of 10 using a balanced incomplete-block schedule, randomized separately within the Sweden and South Africa sites.
- The 10-block cycle presents every scenario exactly 5 times; within-participant presentation order is randomized.
- Each scenario has 6 responses: assistance choice, difficulty, meaningful added value, simpler-alternative adequacy, learning support vs. replacement, and resource–capability trade-off.
- Background/context sections retain the core variables needed for access, inclusion, AI literacy, sustainability, privacy awareness, skills/employability, and comparative interpretation.
- Final reflection contains decision-factor selection, one required synthesis question, and one optional university-support question.
- Study version: `2026-09-v18`.
- Participant-facing completion estimate remains approximately 10–15 minutes.
